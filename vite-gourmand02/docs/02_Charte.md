# Charte Graphique - Vite et Gourmand

## 🎨 Palette Couleurs

| Nom | Hex | Usage |
|-----|-----|-------|
| Vert Principal | #2D5016 | Headers, CTA |
| Vert Clair | #5A8C3A | Accents, hover |
| Crème | #F5F1E8 | Fond |
| Gris Foncé | #2C2C2C | Texte |
| Rouge Accent | #C41E3A | Erreurs, alertes |
| Or | #D4AF37 | Premium, hover |

## 🔤 Typographie

- **Titres** : Playfair Display (serif, elegant)
- **Corps** : Inter (sans-serif, lisible)
- **Mono** : JetBrains Mono (code)

Tailles :
- H1 : 48px (bold)
- H2 : 32px (bold)
- H3 : 24px (semibold)
- Body : 16px (regular)
- Small : 14px (regular)

## 🖼️ Éléments Visuels

- **Logo** : Couronne + fourchette, style minimaliste
- **Icônes** : Feather Icons (24x24px)
- **Boutons** : Arrondi 8px, padding 12px 24px
- **Cartes** : Ombre légère, hover lift
- **Espacement** : Base 8px (multiples de 8)

## 📱 Responsive

- Desktop : 1920px
- Tablet : 768px
- Mobile : 375px

## ♿ Accessibilité

- Contrast ratio : 4.5:1 minimum
- Focus visible sur tous éléments interactifs
- Alt text sur toutes images
- ARIA labels sur formulaires
- Clavier navigation complète

## 🎬 Animations

- Transitions : 300ms ease-in-out
- Hover : scale 1.05
- Loading : spinner animé
- Toast : fade in/out 400ms

## 📸 Photography

- Style : Gastronomie, ambiance chaleureuse
- Éclairage : Naturel ou studio doux
- Composition : Détails des plats en gros plan
- Couleurs : Chaudes, appétissantes

## Brand Voice

- Tonalité : Professionnelle mais chaleureuse
- Vocabulaire : Gastronomique, accessible
- Exemple : "Découvrez nos créations culinaires" (pas "Commandez de la bouffe")
