# Manuel d'Utilisation - Vite et Gourmand
## 🏠 Accueil
- Présentation du restaurant
- Avis clients validés
- Horaires d'ouverture
- Appel à l'action "Commander"

## 📋 Consulter les Menus
- Filtrer par thème (Noël, Pâques, etc)
- Filtrer par régime (Classique, Végétarien)
- Voir détails : plats, allergènes
- Affichage prix selon nombre de personnes

## 🛒 Commander
1. Choisir un menu
2. Indiquer nombre de personnes
3. Choisir date et heure de livraison
4. Entrer adresse de livraison
5. Effectuer paiement (Stripe)
6. Reçoit confirmation par email

## 👤 Compte Client
- S'inscrire avec email
- Se connecter
- Voir mes commandes passées
- Laisser un avis (après livraison)
- Modifier mon profil

## 💼 Compte Employé
- Voir les nouvelles commandes
- Accepter/refuser commande
- Statut : en_preparation
- Statut : en_livraison
- Valider les avis clients

## 🔐 Compte Admin
- Gérer les employés (ajouter/supprimer)
- Statistiques de ventes
- Gérer les menus
- Modérer tous les avis

## 🔒 Sécurité
- Mot de passe hashé (bcrypt)
- Email de confirmation
- Authentification token
- RGPD : droit à l'oubli
- SQL injection : prepared statements
- XSS : htmlspecialchars()
